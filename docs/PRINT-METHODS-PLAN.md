# План: способы печати как в DTF (UV, сублимация…)

Статус: черновик для обсуждения · 26.10.2026
Связан с: `docs/UNIFIED-STOCK-PLAN.md` (единый склад — уже работает на сайте).

## 1. Идея

Печать — это **способ**, изделие — **отдельная вещь со склада или клиента**. Сейчас так устроен только DTF:
строка заказа «DTF-печать» → «Наше изделие (склад)» или «Изделие клиента» → зоны печати по прайсу размеров.

Делаем то же для других способов. Парк оборудования (5 принтеров):

| Способ печати | Принтер | Что печатаем | Расходники |
|---|---|---|---|
| DTF | DTF-принтер | майки, носки, боди (+ изделия клиента) | чернила CMYK+W, плёнка, порошок |
| **UV** | UV-принтер | **ручки, блокноты** + любые изделия клиента (бутылки, чехлы, дерево, стекло…) | чернила CMYK+W, лак |
| **Сублимация** | **Epson L1800** (новый в учёте) | **кружки, подушки, пазлы, брелоки, часы, коврики для мыши** (заготовки со склада) | сублимационные чернила (6 цветов), сублимационная бумага, термоскотч |
| Широкоформат | Широкоформатный | баннеры, плёнки, холст (рулоны) | чернила CMYK, рулоны |
| Лазер | Ricoh C5200 | визитки, флаеры, листовая печать | тонер CMYK, листовая бумага |

Широкоформат и лазер уже устроены по-своему (раскладка по рулону, листы) — их не трогаем. Меняем **UV** и **сублимацию**.

## 2. Решения, которые уже приняты

- Кружки — **сублимация** (Epson L1800), не UV. Сейчас в коде они помечены как UV (`printProcessForProductType`) — это исправится.
- UV на изделии клиента считается **по размеру принта, как DTF** (прайс форматов: розница / дилер).
- **Сублимация — свои заготовки по цене за штуку с тиражными ступенями**, как в прайсе (кружки 1 / 2–9 / 10–50; подушки — цена по ткани; пазлы — по формату). Это тот же механизм, что у маек в DTF: `StockVariant.priceTiers`. Заготовки — категории склада с отметкой «Сублимация» («Кружки», «Подушки», «Пазлы», «Брелоки», «Часы», «Коврики для мыши»). **Прайс по размерам принта сублимации не нужен**, поэтому отдельной карточки на «Складе» нет: нормы расхода (бумага, термоскотч, чернила на изделие) задаются в карточке Epson L1800 на странице «Принтеры».

## 3. Что общего у всех «печатей на изделии»

Одна модель на все способы (DTF, UV, сублимация):

| Понятие | Что это | Где сейчас |
|---|---|---|
| **Способ печати** | код (`dtf`, `uv`, `sublimation`), принтер, настройки и нормы | DTF: `AccountingSettings.dtfSettings` |
| **Прайс форматов** | размер принта → цена розница/дилер | DTF: `DtfPrintPreset` |
| **Изделия для способа** | категории склада с отметкой «Печать X» | уже есть: `StockCategory.printMethods` (сейчас только `dtf`) |
| **Строка заказа** | способ + источник (склад / клиент) + изделие + зоны + количество | DTF: `OrderLine.dtfLineData` |
| **Расход** | по нормам способа → списание с принтера | DTF: плёнка/порошок/чернила через `consumePrinterUse` |

План — **обобщить то, что уже работает в DTF**, а не строить заново.

## 4. Этапы

### Этап A. Принтер Epson L1800 и его расходники (≈1 день) — ✅ сделан 26.10.2026
Миграция `20261026090000_printer_epson_l1800`: принтер `subl` «Epson L1800 (сублимация)», 6 чернил (C/M/Y/K по 20 %, Light C/M по 10 % — стартовые доли), «Сублимационная бумага A4» (лист), «Термоскотч» (м); новые роли слотов `paper` и `tape`.
- Принтер «Epson L1800 (сублимация)» на странице «Принтеры»: 6 цветов сублимационных чернил (C, M, Y, K, Light C, Light M), сублимационная бумага (листы), термоскотч (м).
- Новые категории расходников: «Сублимационная бумага» (лист), «Термоскотч» (м); чернила — в существующей «Чернила».
- Приход по входящим фактурам на эти позиции — сразу.
- Списание при заказе кружек — в этапе D (нужны нормы: листов и см скотча на кружку, мл чернил на площадь).

### Этап B. Общий «прайс и нормы» для способов печати (≈2–3 дня) — ✅ сделан 26.10.2026
Миграция `20261026120000_print_methods`; код — `src/lib/printMethods/`, API `/api/admin/print-methods/[code]/**`, страница `/admin/stock/print/[code]` (`/admin/stock/dtf` → редирект). DTF читает `PrintPricePreset(dtf)` и `PrintMethod('dtf').settings` (цены не изменились); старые `dtf_print_presets` и `accounting_settings.dtf_settings` больше не используются — удалить отдельной миграцией. Нормы UV — стартовые, уточнить после пробных оттисков.
- Таблица `PrintMethod` (dtf, uv; sublimation — только нормы) с принтером и настройками (JSON, по образцу `dtfSettings`).
- Таблица `PrintPricePreset` (способ, название, ширина × высота, розница, дилер) — **переносим туда `DtfPrintPreset`** без изменения цен.
- Страницы «DTF: прайс и нормы» и **«UV: прайс и нормы»** — одна и та же страница для разных способов. У сублимации прайса форматов нет (цена за штуку).
- UV: опции «белила» и «лак» (доплата и норма расхода), нормы мл/см² по цветам.
- Карточки на «Складе» рядом с «Принтерами».

### Этап C. Строка заказа «UV-печать» (≈1 неделя)
- В заказе (админка и кабинет) новый продукт «UV-печать»: **«Наше изделие (склад)» / «Изделие клиента»** — как у DTF.
- **Наше изделие:** выбор из категорий с отметкой «Печать UV» (ручки, блокноты, + новые: зажигалки, флешки…), количество, зоны из прайса UV. Остаток списывается как сейчас.
- **Изделие клиента:** описание («бутылка стеклянная 0,5 л»), количество, размер зоны, фото/файлы, опционально доплата за наладку/пробный оттиск. Склад не трогается.
- Расход UV-чернил по площади принта × норма → UV-принтер (по долям цветов, + белила/лак если выбраны).
- **Ручки и блокноты сохраняют свои конструкторы** (шаблоны, текст, 3D, раскладка ручек на столе для цеха). На этапе C они остаются отдельными продуктами («Ручка», «Блокнот») — UV-печать на них идёт по прежней цене за штуку; новая строка «UV-печать» нужна для остальных изделий и изделий клиента. Объединение — этап E.

### Этап D. Сублимация: кружки, подушки, пазлы, коврики (≈1 неделя)
- Категории «Подушки» (варианты — ткани: сатин 280, габардин 300, лён 320, пайетки 380), «Пазлы» (варианты — форматы: A4/40 — 100, A4/120 — 120, A3/300 — 220, сердце 110/130, магнит A4 170 / A3 250), «Брелоки» (модели mb001–mb010, ступени 1 / 2–9 / 10–50 из прайса, стр. 23–24), «Часы» (35×35 см — 410), «Коврики для мыши» (цены задать — в прайсе нет); отметка «Сублимация» у них и у «Кружек». Цены — тиражные ступени варианта из прайса.
- У кружек в каталоге — перенести ступени 1 / 2–9 / 10–50 из прайса в тиражные цены вариантов.
- Продукт в заказе «Сублимация»: заготовка со склада → количество → файл принта; цена по тиражной ступени (как майки в DTF). Кружки сохраняют свой конструктор.
- Списание с Epson L1800 на изделие: бумага (листов), термоскотч (см), чернила (мл по 6 цветам) — нормы в карточке Epson L1800 («Принтеры»).
- Конструктор кружек и дизайн-студия не меняются.

### Этап E. Объединение (по желанию, позже)
- Ручка/блокнот/кружка становятся «Наше изделие» внутри строк UV / сублимации, а их конструкторы — редакторами для этих категорий. Одна логика цены и расхода для всех изделий.
- Делаем только если после этапов C–D это действительно упростит работу — отдельным решением.

## 6. Открытые вопросы

1. **Расход Epson L1800:** какой формат бумаги (A4 / A3), сколько термоскотча на изделие? Можно взять примерные и уточнить, как с Ricoh.
1a. ✅ Решено по прайсу: подушки, пазлы, кружки — **за штуку с тиражными ступенями** (как майки в DTF).
1b. ✅ Брелоки и часы — **сублимация**.
1c. **Коврики для мыши** — какие цены (в прайсе их нет)?
2. **Изделие клиента в UV:** нужна ли фиксированная доплата за наладку (настройка стола под нестандартное изделие) или пробный оттиск?
3. **Белила и лак в UV:** отдельная доплата в прайсе или входят в цену формата?
4. **Новые UV-категории сразу:** какие изделия, кроме ручек и блокнотов, вы уже печатаете UV со своего склада (зажигалки, флешки, брелоки…)?
5. **Порядок:** предлагаю A → B → C → D (сначала учёт расходников Epson, чтобы фактуры приходовались; потом общий прайс; потом UV-заказы; потом сублимация для кружек).
